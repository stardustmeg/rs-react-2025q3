# React Forms — Dual Forms Approach 🚀📝

A React app with two types of forms (uncontrolled and React Hook Form) using portals, validation, and Redux for state management.

✨ Features:

- **Two modal forms** with different approaches (uncontrolled vs React Hook Form)
- **Reusable modal component** with React Portals
- **Comprehensive validation** (name, age, email, passwords with strength checking)
- **Image upload** with base64 conversion
- **Country autocomplete** from Redux store
- **Responsive design** with proper focus management
- **Data display** on main page with new entry indicators
- Full **accessibility support** (ESC key, outside click, focus management)

🧠 Key Objectives:

- Implement universal modal component with portals
- Set up Redux for form data storage
- Create two forms with different validation logic
- Add comprehensive validation with Zod
- Implement image upload and processing
- Add country autocomplete functionality
- Ensure modal accessibility
